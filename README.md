# Vanuatu-Smart-Transport System 🚍

## 📌 Project Description
This is a cloud-based transport management system that provides a REST API for managing transport routes, users, and services in Vanuatu.

The application is built using a backend server connected to a PostgreSQL database and deployed using Render.

---

## 🏗️ Project Architecture

Frontend (optional) → Backend (Node.js / Express) → PostgreSQL Database (Render)
